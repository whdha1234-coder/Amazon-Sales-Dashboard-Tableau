# 📦 Amazon Sales & Profit Performance Dashboard

An interactive and comprehensive dashboard built using **Tableau Public** to analyze Amazon's sales, profit margins, geographic distribution (Maps), and yearly performance trends.

---

## 📊 Project Overview
This project provides deep insights into Amazon's sales data, featuring geographical customer analysis, profit distribution by sub-category, scatter plots for correlation, and clean KPI metric cards.

---

## 🛠️ Tools & Technologies Used
* **Tableau Public:** 
  * Interactive Maps & Geographic Visualizations.
  * Scatter Plots & Profit Sub-category Bar Charts.
  * Dynamic Filters (Order Date, Region, Country).
